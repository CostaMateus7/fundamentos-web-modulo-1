# Página pessoal — Fundamentos Web

Este projeto foi desenvolvido como atividade do **Módulo 1 da disciplina de Fundamentos Web**, do curso de **Tecnologia da Informação da Universidade Federal de Mato Grosso do Sul (UFMS)**.

## Objetivo

O objetivo da atividade é aplicar os conhecimentos introdutórios de HTML e CSS por meio da criação de uma página pessoal. A página apresenta informações sobre minha formação, minha trajetória profissional, meus conhecimentos e meus principais interesses.

## Conteúdo da página

A página contém:

- apresentação pessoal;
- foto profissional;
- formação acadêmica;
- cursos e conhecimentos;
- trajetória profissional na Ótica M3 Óculos;
- principais interesses;
- cidade e informações de contato;
- link para o perfil profissional no LinkedIn.

## Recursos utilizados

Durante o desenvolvimento, foram utilizados os seguintes recursos:

- estrutura básica de um documento HTML;
- títulos e subtítulos;
- parágrafos e formatação de texto;
- listas ordenadas e não ordenadas;
- inserção de imagem com texto alternativo para acessibilidade;
- link externo para o LinkedIn;
- organização visual com CSS;
- cores, espaçamentos, bordas e sombras;
- adaptação da página para diferentes tamanhos de tela.

## Como visualizar

1. Faça o download ou extraia a pasta do projeto.
2. Mantenha os arquivos na estrutura indicada acima.
3. Abra o arquivo `index.html` em um navegador de sua preferência.

## Acessibilidade

A imagem possui uma descrição no atributo `alt`, permitindo que seu conteúdo seja identificado por leitores de tela. A página também utiliza títulos organizados, textos legíveis e contraste entre o conteúdo e o fundo.
